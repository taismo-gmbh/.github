## Was wir unter GEO verstehen

Generative Engine Optimization ist bei uns kein Zusatz hinter dem SEO, sondern die Hälfte
der Arbeit. Sie besteht aus vier Teilen, und wer nur einen davon macht, macht kein GEO:

1. **Entitätenaufbau.** Das Unternehmen muss als eigenständige, wiedererkennbare Einheit
   existieren, nicht als Sammlung von Seiten.
2. **Strukturierte Daten.** Die Entität wird maschinenlesbar verknüpft, über JSON-LD mit
   sauberen `@id`-Referenzen statt isolierter Auszeichnungen.
3. **Zitierfähige Inhalte.** Texte, aus denen ein Modell eine Aussage herauslösen kann,
   ohne den Rest zu brauchen.
4. **Messung.** KI-Sichtbarkeit wird erhoben, über mehrere Systeme hinweg, nicht behauptet.

GEO ersetzt SEO nicht. Eine Seite, die nicht rankt, wird auch nicht zitiert.
